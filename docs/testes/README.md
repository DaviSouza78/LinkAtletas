Comece pelo [relatório de testes](../relatorio-testes.md): ele descreve cenários, resultados e referências. Os testes executáveis ficam em [tests](../../tests/README.md); os arquivos de comprovação ficam em [evidencias](../evidencias/README.md).

| Material | O que documenta |

Neste projeto, testes de **API** se referem à API própria do LinkAtletas. A conferência de CREF é manual; a existência desses testes não indica integração automática com um conselho profissional.

Um relatório de auditoria de código e um percurso de navegador comprovam verificações diferentes. As contagens de reexecuções não devem ser somadas como novos casos.
