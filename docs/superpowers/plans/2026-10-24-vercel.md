# Preparação da Vercel Implementation Plan

**Goal:** preparar a entrada Fastify, tarefas agendadas e instruções de configuração para o domínio publicado.

**Architecture:** servir `dist` e `/api` pelo Fastify existente. Persistência externa; cron autenticado com exclusão mútua no PostgreSQL; consulta periódica de conversas entre instâncias.

**Tech Stack:** Node 24, Fastify, PostgreSQL, Vite, Vitest, Vercel.

## Tarefas

- [x] Criar `server.ts` importando `./server/index.js`; configurar `vercel.json` com preset Fastify e inclusão de `dist/**` na função.
- [x] Criar `server/scheduled.ts` com registro de `/api/internal/jobs`, comparação segura do Bearer e trava de sessão PostgreSQL durante `runJobs`. Liberar a conexão em todos os caminhos.
- [x] Registrar a rota na entrada existente. Criar o timer de jobs apenas quando `VERCEL !== '1'`, preservando a execução local.
- [x] Adicionar consulta periódica nas páginas de mensagens e notificações, com limpeza no unmount e apenas enquanto a página está visível.
- [x] Criar `tests/unit/scheduled.test.ts`: negar segredo ausente/incorreto, aceitar segredo correto, evitar execução concorrente e liberar trava após erro.
- [x] Incluir a entrada raiz em `tsconfig.server.json` e documentar variáveis, Neon, armazenamento privado, SMTP, migrações e pendências em `docs/evolucao/vercel.md`.
- [x] Executar `pnpm typecheck`, `pnpm exec vitest run tests/unit`, `pnpm build` e `pnpm docs:check`. Registrar resultados efetivos e a indisponibilidade do Docker se persistir.
- [x] Conferir diff, ASCII e comentários novos. Commitar na branch de preparação; manter main funcionando até os serviços serem configurados.
