## Documento oficial

A ERS oficial é o **PDF final ajustado pela equipe**, indicado acima. Não há um Word final equivalente publicado. As fontes em Markdown e os arquivos do template apoiam a elaboração, mas não reproduzem necessariamente os ajustes manuais do PDF final.

Versões anteriores podem ser consultadas pelo histórico do Git. Resultados de testes preservam sua própria data e não comprovam novas execuções.
