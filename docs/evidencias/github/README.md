# Registros de versionamento e integração

Os JSONs desta pasta preservam metadados de pull requests e execuções da integração contínua utilizados na entrega. Campos como commit, URL, status e conclusão permitem localizar a execução original.

- `github-pr-*`: integração das etapas do projeto por pull request.
- `github-ci-*`: resultados de execuções específicas; a data e o commit definem o alcance.

Os registros antigos não representam automaticamente a versão atual da aplicação. Para conferir publicação e repositórios, use o [guia de versionamento](../../operacao/publicacao.md); para conhecer os testes executados, use o [relatório](../../relatorio-testes.md).
