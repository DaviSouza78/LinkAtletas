# Conferência da documentação

[documentation-check.json](documentation-check.json) é gerado por `pnpm docs:check`. Registra links relativos conferidos, caminhos OpenAPI, colunas/relações do DER e chamadas dos diagramas de sequência.

O comando não testa serviços externos, não executa jornadas de usuários e não comprova sozinho que o banco implantado corresponde ao esquema exportado.
