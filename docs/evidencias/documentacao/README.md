# Conferências documentais

| Arquivo | Finalidade |
|---|---|
| [documentation-check.json](documentation-check.json) | Resultado do conferidor de links locais, OpenAPI e coerência dos diagramas. É atualizado por `pnpm docs:check`. |
| [checklist-links-2026-10-26.json](checklist-links-2026-10-26.json) | Conferência datada dos endereços usados no checklist da entrega. |

A conferência de links valida referências, não o conteúdo de todos os requisitos ou o funcionamento do site. Os [arquivos do template](../../template/README.md) e a [ERS final](../../ERS-template-original-atualizada.pdf) têm funções distintas. Registros intermediários de conversão permanecem recuperáveis no [histórico](https://github.com/DaviSouza78/LinkAtletas/tree/094ed35704a4620eb358e217b7ee7b1c5cda22e0/docs/historico/README.md).
